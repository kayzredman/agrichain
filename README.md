# agriChain

A shared custody record for agricultural lots: what the food is, where it grew, and who kept the value.

Design and notes live in [`docs/`](docs/README.md). That folder is the source of truth. Start with the [brief](docs/brief.md), then the [system design](docs/system.md). The build document is the [blueprint](docs/blueprint.md). The Word copy is [agriChain Solution Blueprint.docx](docs/agriChain%20Solution%20Blueprint.docx).

Source episode: [Food and the Fight for Global Security](https://www.youtube.com/watch?v=P-qcYDpPTB4) (Siren Investigates, Genevieve Leveille, AgriLedger).
